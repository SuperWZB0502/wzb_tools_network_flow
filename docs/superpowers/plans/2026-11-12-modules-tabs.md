# 模块库、子流程页签和连线重接实施计划

**Goal:** 完成用户的8项交互更新并更新既有 GitHub Pages 与 Sites。

**Architecture:** 保留 SVG / Rough.js 编辑器和递归文档格式。模块定义与实例化独立为 catalog.mjs，页签管理独立为 tabs.mjs，导航动画与模块库 DOM 放在 workspace-ui.mjs；模型负责原子重接和依赖约束，editor 负责手势与持久化。

**Tech Stack:** 原生 ES modules、SVG、Web Animations、localStorage、现有 Edge / Node 测试。

## 约束与设计

- 原有严格时间依赖、不重叠、手绘风格、固定泳道标志格、递归展开、复制/导出和容量保护全部保留。
- 连线选中后显露两个可拖端点；松到同一流程其他组件的端口或本体完成重接，保留连线 ID；空白、跨流程、自连、成环或重复连接恢复原线。
- 页签根流程常驻，已打开的子流程切换后仍保留；仅点击 × 关闭。缩小按钮回到父流程，不关闭子页签。各页签保留缩放和滚动位置，文档删除/替换时清理失效页签。
- 从组件矩形向画布展开，缩小时反向收回，约320ms；尊重减少动态效果偏好。
- 每5000ms保存根文档、自定义模块和页签；保留输入框中未失焦的文字，不触发失焦或破坏编辑；拖动中的临时预览不保存。
- 基础形状后放“自定义模块”；支持以名称封装当前整个流程，保留完整递归图，重复实例必须生成全新 ID。
- “常用模块”：Embedding、TransformLayer → AttentionNorm、SelfAttention、MLPNorm、MLP。TransformLayer实例自身以此命名，子流程为计算泳道中依序连接的四个过程，蓝色。
- “常用通信模块”：AllReduce、AllGather、ReduceScatter、AllToAll、Send、Recv，绿色。
- 每个分类标题和所有叶模块都能拖入，分类实例带预置子流程；自定义分类整体为全部已存模块的封装。

## 实施步骤

- [ ] 为 reconnectEdge 和 catalog 实例化/分类/克隆写失败测试，运行确认失败，再实现并跑绿。
- [ ] 实现模块仓库 DOM、封装对话框和模板拖放；验证 TransformLayer 四步链、通信颜色、顶层分类、自定义完整图与 ID 隔离。
- [ ] 实现 persistent tabs、父级缩小和展开/缩回动画；验证切换保留、关闭仅移除页签、恢复视图及已删除节点清理。
- [ ] 实现选中连线端点和重接预览；验证起点/终点、取消、无效环与重接后的时序。
- [ ] 实现5000ms保存及草稿快照；验证刷新恢复未失焦文字、页签和自定义模块，拖动/错误/存储失败不损坏文档。
- [ ] 运行完整模型/浏览器套件，独立审查修复，再推送既有仓库并验证线上行为。

## 复查重点

重接失败的原子回滚；多个同名模板重复实例的全局 ID 唯一性；子页签关闭不删除数据；5秒保存不能打断输入或保存半成品拖动；恶意/损坏本地模块条目和嵌套容量上限。
