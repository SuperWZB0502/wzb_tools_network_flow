# 严格数据依赖时间顺序

每条依赖 from→to 都满足 to.x ≥ from.x + from.width + 12。

统一模型调度覆盖连线、拖动、左右微调、边缘和属性改宽、分组移动、粘贴与旧图导入。按依赖拓扑顺序推迟组件，保留已有空隙，不将其他过程提前；同泳道无法满足的旧顺序按依赖关系调整，并始终防止重叠。子流程独立执行相同约束。循环依赖仍拒绝。

渲染器对动画采样和自由拖动预览也执行相同约束，避免完成后正确、操作中倒序。旧图读取时保留节点和连线 ID 并迁移时间位置，撤销/重做和 JSON 持久化保留约束。

验证：模型反向连接、多前置分支和相邻过程、前后置拖动、尺寸变化、同泳道换位、分组与递归导入；真实浏览器连线、属性变更、撤销、拖动中间帧和刷新。运行完整原有交互回归，独立审查，再提交到既有 GitHub 仓库并更新 GitHub Pages 与原 Sites。
