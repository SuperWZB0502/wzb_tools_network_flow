# 网络流程画板

按用户列出的十项要求实现独立网页，用横向计算、通信、拷贝泳道表达网络执行过程，方便人工观察时间重叠与数据依赖。

默认三条空白泳道依次为计算流（#e8f3ff）、通信流（#e9f7ed）、拷贝流（#fff7d9）。新增泳道只提供这三种类型，可改名。泳道有专用拖动手柄；复制整条泳道含组件和内部连线，跨泳道连线不复制。

左侧提供矩形、圆角矩形、椭圆、菱形、平行四边形和胶囊，及常用计算/通信/拷贝预设。Pointer Events 统一处理拖动、缩放和连线。组件允许横向任意位置、泳道内纵向位置及跨泳道拖动；同泳道禁止横向重叠，拖过相邻组件中心自动换位，必要时向右推开。宽度代表示意时长，未赋予真实物理时间。左右边缘缩放，左右中心圆点连接三次贝塞尔曲线，箭头为有向依赖。

双击文本浮层编辑，支持换行、水平左中右与垂直上中下九种组合。单击选中，左右箭头移动1px，Shift+箭头移动10px。复制/剪切/粘贴适用于选中组件或泳道；撤销重做、删除、JSON导入导出、SVG/PNG导出、本地自动保存作为完整编辑工具必要支持。

布局：浅色纸面、石墨色细线、Rough.js稳定随机种子手绘边框；左组件库、中心可滚动缩放画板、右属性栏。仅绘图元素手绘，界面控件保持清楚可读。默认空白，提供可主动载入的重叠示例。

实现选择：原生ES modules + SVG，静态部署；无后端和登录依赖，数据保存在浏览器和用户导出的文件。单一选中对象；不实现自动调度/自动判断性能收益。浏览器鼠标测试覆盖交互，Node测试覆盖布局和克隆关系。
