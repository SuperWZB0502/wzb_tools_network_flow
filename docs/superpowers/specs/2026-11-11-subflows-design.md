# 平滑交互与递归子流程

以用户本轮 11 项要求为准，保留既有画板与数据。

1. 组件落位后始终位于泳道中线，迁移旧文件的 offsetY 为 80。拖动期间采用自由浮动预览，保持来源泳道颜色；仅松手时提交新的泳道归属和位置。同泳道相邻组件换位、泳道上下重排及松手吸附采用约 180ms 缓动。
2. Ctrl/Command+单击切换多选；空白处拖框选中完整落入范围内的组件，Ctrl可累加。多选可一起拖动、微移、复制、剪切和删除，内部依赖一起复制。
3. W/S 只改变横向比例；A/D 平滑水平平移，长按连续执行；输入框和弹窗不拦截文字键。
4. 两侧面板可按钮收起到窄栏，并可拖动边缘调整宽度。右键泳道可选择三种类型新建及删除；右键组件可删除，支持批量删除。
5. 每个组件有可选 subflow 文档。右上角双角扩展图标进入独立的子流程编辑页（同站点新页面视图和URL hash），默认三条空泳道，支持面包屑和返回、独立编辑，保存/导出仍包含整个根文档。
6. 右下角两个图标分别切换“展开一级”和“递归展开全部”，再次点击收起。展开在原组件位置内显示子流程的真实泳道、组件与依赖；父组件扩大，当前层右侧内容按需让出横向空间；收起恢复。展开仅改变投影视图，不永久移动原始时序数据。子流程内仍可继续新增组件并创建下一级子流程。
7. JSON递归保存、导入与复制完整子树，ID全部重映射；兼容旧文档。层级校验防止过深或过大输入。撤销重做覆盖子流程编辑、展开状态及批量操作。

实现：model.mjs 增加递归文档、组移动与复制；layout.mjs 计算展开投影与层级场景；app.mjs 处理场景、缓动和手势。Rough.js与原风格不变。
