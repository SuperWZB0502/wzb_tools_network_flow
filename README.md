# 网络流程画板

一个手绘风格的网络计算、通信、内存拷贝流程编辑器。独立静态网页，使用 Excalidraw 同款 Rough.js 4.6.4 绘制稳定的手绘形状。

## 使用

- 默认计算流（浅蓝）、通信流（浅绿）、拷贝流（浅黄）三条空白泳道。新增泳道提供这三类；选中名称可改名或改变类型。
- 拖住泳道名称左侧的六点手柄上下排序；单击名称后可 Ctrl+C / X / V 复制、剪切、粘贴整条泳道，内部组件和内部依赖线一同复制。
- 拖动左侧六种形状或常用过程到任意泳道。组件支持泳道内自由位置和跨泳道拖动，同泳道保持横向无重叠，拖过相邻组件中心自动换位。
- 双击组件改文字，回车换行、Ctrl+回车完成、Esc取消。右侧支持左/中/右与上/中/下九种文字对齐、字号、颜色、形状、位置和宽度。
- 单击选中后，左右箭头微移1px，Shift+左右箭头微移10px。抓住左右边缘调整宽度；从左右中心圆点拖到另一组件圆点创建有向贝塞尔曲线。
- Ctrl+C / X / V 对选中组件生效。Delete删除，Ctrl+Z撤销，Ctrl+Shift+Z或Ctrl+Y重做。禁止自连、重复依赖和循环依赖。
- 按空格拖动或选择手形工具平移，Ctrl+滚轮或底部按钮缩放。适应画布按钮显示完整流程。
- 自动保存在当前浏览器；导出JSON可重新编辑，SVG/PNG适合文档。完整导出不受当前画布滚动和缩放影响。更换浏览器前请保存JSON。
- “载入示例”提供计算与通信重叠的可编辑示例，会先确认替换且可撤销。

横向刻度为相对单位，宽度表达相对时长。本工具供人工推演依赖与重叠，不自动测量真实性能或计算掩盖收益。

## 本地运行与验证

需要Node.js。页面运行不依赖外部CDN、后端或包安装。

```sh
npm start
# 打开 http://127.0.0.1:4173
```

模型测试：`node --test tests/model.test.mjs`。浏览器测试依赖Playwright及已有Microsoft Edge；先启动本地服务器，安装或提供Playwright后运行 `npm test`。

源码：`dist/model.mjs`管理布局和文档校验；`dist/app.mjs`管理SVG、鼠标手势与编辑；`dist/style.css`管理响应式界面。静态托管直接使用`dist/`。Rough.js许可证随库保存在`dist/vendor/ROUGH-LICENSE.txt`。

11项模型测试；真实Edge浏览器覆盖组件拖入、双击多行文字、对齐、键盘微移、复制剪切粘贴、换位、两侧缩放、曲线连线、整条泳道克隆与重排、三类新增、撤销重做、自动保存、有效/无效JSON导入、JSON/SVG/PNG导出、140%缩放和双向滚动下的拖动、跨泳道自由放置、属性编辑事件、平移和390px窄屏。
