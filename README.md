# 网络流程画板

一个手绘风格的网络计算、通信、内存拷贝流程编辑器。独立静态网页，使用 Excalidraw 同款 Rough.js 4.6.4 绘制稳定的手绘形状。

## 使用

- 首次打开包含计算流（浅蓝）、通信流（浅绿）、拷贝流（浅黄），每条各一个样例组件，依赖顺序为计算→拷贝→通信。已有自动保存内容优先恢复；新建空白画板与新子流程仍提供三条空泳道。新增泳道提供这三类；选中名称可改名或改变类型。
- 拖住泳道名称左侧的六点手柄上下排序；单击名称后可 Ctrl+C / X / V 复制、剪切、粘贴整条泳道，内部组件和内部依赖线一同复制。
- 拖动左侧六种形状或常用过程到任意泳道。拖动时组件可以自由跟随鼠标，保持来源颜色；松手后才插入目标泳道、换色并吸附到中线。落位后纵向位置固定，同泳道横向不重叠，换位和泳道排序具有缓动动画。
- 双击组件改文字，回车换行、Ctrl+回车完成、Esc取消。右侧支持左/中/右与上/中/下九种文字对齐、字号、颜色、形状、位置和宽度。
- 单击选中后，左右箭头微移1px，Shift+左右箭头微移10px。抓住左右边缘调整宽度；从左右中心圆点拖到另一组件圆点创建有向贝塞尔曲线。
- 连线建立后强制遵守时间依赖：后置组件起点至少比前置组件终点晚 12px。新增连线、拖动、微调和改宽会自动推迟后续过程，连续依赖及同泳道相邻过程一起让位。拖动预览和动画中也保持先后关系；旧图打开时自动校正，子流程内同样生效。
- Ctrl+C / X / V 对选中组件生效。Delete删除，Ctrl+Z撤销，Ctrl+Shift+Z或Ctrl+Y重做。禁止自连、重复依赖和循环依赖。
- 单击连线后，两端出现紫色拖动手柄，可将起点或终点拖到同一流程的其他组件端口或本体。重接保留连线身份并校正时间顺序；空白、跨流程、自连、重复和成环重接恢复原线，Esc可取消。
- 按空格拖动或选择手形工具平移，Ctrl+滚轮或底部按钮缩放。适应画布按钮显示完整流程。
- W/S 以鼠标所在位置为中心横向放大/收缩，长按从慢到快加速；A/D 左右平移。横向缩放只改变时间位置与宽度，文字字号和泳道标志格宽度固定。文字放得下时保留指定对齐，放不下时左对齐并在右侧省略；滚动时组件与连线在固定标志格的分界线处裁切。输入文字时这些键仍用于正常输入。
- Ctrl/Command+单击切换多选；从空白处拖动框选完整落入范围的组件，Ctrl可累加。多选支持整体拖动、微移、复制、剪切、粘贴和删除，保留内部依赖与子流程。
- 两侧面板顶部箭头可向左右收起，也可拖动面板边缘调节宽度。右键泳道可按三种类型新建或删除；右键组件可以删除。
- 组件右上角双角图标以展开动画打开子流程。已打开的页签会保留，切回主流程后仍可直接再选；子页签右侧×仅关闭页签，不删除流程数据。子流程的缩小按钮以收回动画返回父流程，保留当前页签。每个页签记住自己的缩放和滚动位置，刷新后可恢复。新子流程默认仍有三类泳道。
- 组件右下角两个图标分别展开一级与所有递归子流程，再次点击收起。展开后真实子泳道、组件和连线内联显示，右侧内容平滑让位；收起恢复原位置。已展开的内部组件仍可以继续逐级展开或收起。
- 每5秒自动保存到当前浏览器，编辑提交时也即时保存；包含未失焦的文字和有效数值草稿、页签视图、自定义模块及分类收拢状态，拖动预览不进入保存。在任何层级导出JSON都会包含完整根文档及所有子流程。SVG/PNG导出当前流程视图（含展开内容），不受滚动和缩放影响。更换浏览器前请保存JSON。最多20级、3000个组件、300个流程；超过限制的操作会保留原图。
- 组件仓库提供蓝色计算模块 Embedding、TransformLayer；后者带有依次连接的 AttentionNorm、SelfAttention、MLPNorm、MLP。绿色通信模块包含 AllReduce、AllGather、ReduceScatter、AllToAll、Send、Recv。分类标题、TransformLayer中间分类和叶模块都可拖入，分类实例自带预置子流程。
- 基础形状下的“自定义模块”可以封装当前完整流程及递归内容，最多100个。保存后拖入产生独立副本，可修改子流程且不影响模板或其他实例。自定义库保存于当前浏览器；JSON导出包含已拖入画板的实例。
- “载入示例”提供计算与通信重叠的可编辑示例，会先确认替换且可撤销。

横向刻度为相对单位，宽度表达相对时长。本工具供人工推演依赖与重叠，不自动测量真实性能或计算掩盖收益。

## 本地运行与验证

需要Node.js。页面运行不依赖外部CDN、后端或包安装。

```sh
npm start
# 打开 http://127.0.0.1:4173
```

模型测试：`node --test tests/model.test.mjs`。浏览器测试依赖Playwright及已有Microsoft Edge；先启动本地服务器，安装或提供Playwright后运行 `npm test`。

源码：`dist/model.mjs`管理递归文档和校验；`dist/layout.mjs`生成可逆展开布局；`dist/renderer.mjs`管理SVG与稳定DOM动画；`dist/editor.mjs`管理导航、多选与手势；CSS管理响应式界面。静态托管直接使用`dist/`。Rough.js许可证随库保存在`dist/vendor/ROUGH-LICENSE.txt`。

## 已验证

`npm test`自动运行40项模型/布局测试及14组Edge浏览器验收，涵盖原有交互和严格时间依赖、端点重接与回滚、模块分类和递归副本、自定义库、子页签关闭和恢复、展开/缩回动画、5秒草稿保存和拖动隔离。未启动本机预览时测试会自行启动并清理服务器。
